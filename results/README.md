# Generated results

These files are regenerated by `uv run python scripts/reproduce.py`:

- `metrics.json`: headline metrics with numerators, denominators, inclusion and exclusion counts;
- `window_sensitivity.csv`: coverage under the three predeclared temporal windows;
- `recovery_windows.csv`: row-level trace from each included recovery label to matched operation-log rows;
- `SHA256SUMS.txt`: checksums of the three result files above.

The files contain no generation timestamp, so a rerun against identical inputs is byte-stable.

# Generated results

These files are regenerated by `uv run --frozen python scripts/reproduce.py`:

- `metrics.json`: headline metrics with numerators, denominators, inclusion and exclusion counts, and the background/null summary per window (`schema_version: 2`);
- `window_sensitivity.csv`: coverage under the three predeclared temporal windows;
- `background_null.csv`: observed coverage against the random-anchor background for every window crossed with both anchor domains and both resampling schemes; `variant_role` marks the primary variant;
- `recovery_windows.csv`: row-level trace from each included recovery label to matched operation-log rows, including whether the anchor falls inside the experiment's observable log interval;
- `figures/recovery_activity_vs_background.png`: observed coverage against the null distribution for the three windows;
- `SHA256SUMS.txt`: checksums of the five files above.

No file contains a generation timestamp, and the null uses a fixed seed, so a rerun
against identical inputs is byte-stable.

The null construction, its inclusion rules, and what it does and does not license are
documented in [`../METHODOLOGY.md`](../METHODOLOGY.md) section 7.
